## 1. Цель работы

Разработать аналитическую витрину на основе подготовленных данных слоя staging для анализа зависимости количества аренд велосипедов от сезона и погодных условий.

## 2. Источник данных

Входные данные читаются из S3 непосредственно с использованием DuckDB:

`s3://staging/bike-sharing/source_ingested_on=2026-10-18/staging.parquet`

## 3. Реализованные задачи

- Разработана модель аналитической витрины `hourly_rentals`.
- Определена гранулярность: одна запись соответствует одному часовому наблюдению.
- Определён ключ записи: `dteday + hr`.
- Выполнено сопоставление полей слоя staging и аналитической витрины.
- Сохранены данные и флаги качества.
- Реализована запись результата в формате Parquet с возможностью повторного запуска.
- Подготовлен групповой запрос для анализа аренд по сезонам и погодным условиям.

## 4. Расположение результата

Аналитическая витрина сохраняется в S3:

`s3://mart/bike-sharing/source_ingested_on=2026-10-18/hourly_rentals.parquet`
