# Лабораторная работа № 5
## Расчёт метрик и подготовка данных для анализа

**Авторы:** Попов Никита, Гордий Владимир  
**Группа:** ИВТ-241

## 1. Цель работы

Рассчитать метрики на основе аналитической витрины Bike Sharing, проверить полученные результаты и подготовить данные для дальнейшего анализа зависимости количества аренд велосипедов от сезона и погодных условий.

## 2. Источник данных

Для расчётов используется аналитическая витрина, подготовленная в лабораторной работе № 4:

`s3://mart/bike-sharing/source_ingested_on=2026-10-18/hourly_rentals.parquet`

Чтение данных выполняется непосредственно из S3 с использованием DuckDB.

**Гранулярность:** одна строка соответствует одному часовому наблюдению спроса на прокат велосипедов.

**Основной показатель:** `rentals_count` — количество аренд велосипедов за один час.

## 3. Реализованные задачи

- Рассчитаны общий итог и основные метрики: среднее и медианное количество аренд.
- Выполнена основная группировка данных по сезонам.
- Выполнена уточняющая группировка по сезонам и погодным условиям.
- Рассчитана доля каждого сезона в общем количестве аренд с использованием оконной функции.
- Подготовлена отдельная выборка исходных почасовых значений для последующего анализа распределения.
- Созданы три временные таблицы DuckDB для использования в лабораторной работе № 7.
- Реализованы проверки корректности полученных расчётов.

## 6. Подготовленные результаты

В памяти DuckDB созданы три временные таблицы:

- `metrics_by_season` — метрики и доли аренд по сезонам.
- `metrics_by_season_weather` — метрики по сезонам и погодным условиям.
- `hourly_rental_values` — отдельные почасовые значения количества аренд для дальнейшего анализа.

Промежуточные таблицы не сохраняются в отдельные файлы.
