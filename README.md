# Лабораторная работа № 6
## Документирование аналитического контура Bike Sharing

**Авторы:** Попов Никита, Гордий Владимир  
**Группа:** ИВТ-241

## 1. Цель работы

Документировать аналитический контур проекта Bike Sharing Dataset, описать происхождение и движение данных от первоисточника до результатов аналитики, проследить путь выбранной метрики до исходных полей и проанализировать влияние возможного изменения формулы расчёта.

## 2. Источник данных

**Первоисточник:** Bike Sharing Dataset, UCI Machine Learning Repository.

**Исходный файл:** `hour.csv`.

**Фактический HTTP-источник загрузки по умолчанию:** закреплённый GitHub Raw URL, используемый в Airflow DAG `ingest_raw`.

Исходный объект сохраняется в S3:

`s3://raw/bike-sharing/ingested_on=2026-10-18/hour.csv`

Данные описывают почасовые наблюдения проката велосипедов за период с 2011-01-01 по 2012-12-31.

## 3. Реализованные задачи

- Составлена схема Data Lineage, отражающая движение данных от первоисточника до результатов ЛР № 5.
- Описана загрузка исходных данных в слой `raw` с использованием Airflow DAG `ingest_raw`.
- Прослежены этапы подготовки данных в `staging`, формирования отдельного результата `quarantine` и построения аналитической витрины `mart`.
- Описаны основные преобразования, проверки качества данных, ключи и правила отбора записей.
- Прослежен путь выбранной метрики `avg_rentals_per_hour` от результата аналитики до исходного поля `cnt` файла `hour.csv`.
- Подготовлен словарь пяти ключевых полей с указанием типов данных, источников и преобразований.
- Указано расположение полного сопоставления полей аналитической витрины в `docs/mart.md`.
- Выполнен анализ влияния замены среднего значения (`AVG`) на медиану (`MEDIAN`).

## 4. Прослеживание выбранной метрики

Для анализа выбрана метрика среднего количества аренд за час для группы:

- `season = 3`;
- `weathersit = 1`.

**Результат:** 244,49 аренды за час.

Показатели выбранной группы:

- Количество часовых наблюдений: 3 280.
- Количество непустых значений: 3 280.
- Общее количество аренд: 801 941.
- Среднее количество аренд за час: 244,49.
- Медианное количество аренд за час: 210.

Расчёт среднего значения:

`801 941 / 3 280 = 244,494207... ≈ 244,49`

Результат находится в ноутбуке `notebooks/calculate_metrics.ipynb`, ячейка 16 (`In [8]`), в DataFrame `metrics_by_season_weather_result`.

## 5. Анализ влияния изменения формулы

Рассмотрен сценарий замены формулы среднего количества аренд `AVG(rentals_count)` на медиану `MEDIAN(rentals_count)` в группировке по сезону и погодным условиям.

Для выбранной группы результат изменяется:

- Среднее значение: 244,49.
- Медиана: 210.

Изменение затронет аналитический результат `metrics_by_season_weather` и материалы, использующие эту метрику.

При изменении только данной группировки исходный датасет, слои `raw`, `staging`, `quarantine`, аналитическая витрина `mart`, количество строк и сумма аренд останутся без изменений. Самостоятельные расчёты `overall_metrics` и `metrics_by_season` также не изменятся.
