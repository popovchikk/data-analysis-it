## Отчёт о качестве данных

## 1. Контекст

**Аналитический вопрос:** как различается количество аренд велосипедов в зависимости от сезона и погодных условий?

**Датасет:** Bike Sharing Dataset, UCI, файл `hour.csv`.

**Входной S3-путь:**

```text
s3://raw/bike-sharing/ingested_on=2026-10-18/hour.csv
```

**Смысл строки:** одно почасовое наблюдение.

**Бизнес-ключ:** `dteday + hr` — дата и час наблюдения. Ограничение принято для проверки уникальности почасовых записей.

Профилирование выполнялось напрямую из `raw` через DuckDB.

## 2. Профиль

В `raw` получено **17 379 строк**. DuckDB показывает 18 столбцов: 17 полей исходного `hour.csv` и партиционный столбец `ingested_on`, полученный из S3-пути.

Для ключевых полей `dteday`, `hr`, `season`, `weathersit` и `cnt` проверено по 17 379 строк. Пропусков не обнаружено: для всех этих полей `missing_rows = 0`, доля пропусков `0.0`.

Повторы по бизнес-ключу `dteday + hr` отсутствуют:
- `duplicate_groups = 0`;
- `duplicate_extra_rows = 0`.

Период наблюдений: **2011-01-01 — 2012-12-31**.

Распределение по часам показывает выраженную внутридневную разницу спроса. Среднее число аренд минимально в **04:00 — 6,35**, а максимально в **17:00 — 461,45**.

Таким образом, данные пригодны для дальнейшего сравнения спроса по времени, сезонам и погодным условиям.
